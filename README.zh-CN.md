# 翻译语料查看器

[English](README.md) · 简体中文

浏览、搜索、编辑和校验本地 JSONL 或 CSV 语料。一份语料支持一种源语言和多种目标语言。公开版在浏览器中运行，并附有完整版目录、抓取任务、语料 API 和提交流程的[接口声明](contracts/full-tool.d.ts)。

## 快速开始

1. 从原始文件视图保存 [index.html](index.html)，或在仓库压缩包中找到它。双击即可在浏览器中打开。用 **English** 和 **简体中文** 按钮切换界面语言。
2. 选择本地 JSONL 或 CSV 文件，或从侧栏载入虚构样例。下方也提供独立的样例文件。
3. 点击显示的 **源语言** 可更改语言。选择 **目标语言** 标签页可切换要搜索、筛选、校验或编辑的译文，键盘方向键也可切换。使用 **添加目标语言** 新增译文列。旧版文件可先通过 **命名目标语言** 给已有译文添加语言标签。
4. 将整份语料及所有目标语言导出为 JSONL 或 CSV。重新打开导出的文件即可继续编辑。

HTML 中已打包 React 查看器、样式和虚构样例。这一个文件可以移动到其他目录离线打开。编辑暂存在当前页面，导出后由你保存。搜索和筛选只影响页面显示。

### 示例一 · BGA 风格桌游

载入 **BGA 风格桌游**，或导入[桌游 JSONL](examples/bga-style-demo.jsonl)。样例包含 6 条虚构的英中词条。选择 **校验有提示**，可以找到空译文、漏掉的占位符和缺失的标记。编辑 `orchard-demo-03`，在译文中保留 `{bellTime}`，再导出 JSONL 保存草稿。

### 示例二 · 写作应用界面本地化

载入 **应用界面文案**，或导入[应用界面 CSV](examples/app-ui-demo.csv)。查看一款虚构写作应用的导航标题、状态消息和多行导出说明。选择 **未翻译**，补写 `ui-demo-04` 的译文，再导出 CSV 交给同事。

### 示例三 · 多语言野外指南

载入 **多语言野外指南**，或导入[虚构指南 JSONL](examples/multilingual-demo.jsonl)。原文为西班牙语，目标语言包括英文、简体中文和阿拉伯语。切到阿拉伯语后用 **未翻译** 找到 `guide-demo-02`，切回英文可看到同一词条已有译文。导出任一格式都会保留三种语言。

## 公开版与完整版

公开版提供本地文件工作流。完整版还包括模块目录、抓取任务、写入磁盘的语料和快照，以及提交流程。公开仓库通过类型声明和参考文档保留这些接口。详见[版本对照和接口参考](docs/full-tool.zh-CN.md)，其中列出了功能、命令名称和本地路由。

## 文件格式

文件使用 UTF-8 编码。JSONL 每行包含一个对象，CSV 第一行为表头。词条必填字段为 `source`，可选字段为 `id` 和 `context`。可以用 `source_locale` 指定整份语料的一种源语言，例如 `es`。缺少该字段的词条会沿用文件中其他词条指定的源语言。

| 格式 | 现有单目标语言 | 带语言标签的译文 |
| --- | --- | --- |
| JSONL | `target` 文本字段 | 以语言标签为键的 `translations` 对象，例如 `{"zh-CN":"...", "fr-FR":"..."}` |
| CSV | `target` 列 | 每种语言一列，例如 `target:zh-CN,target:fr-FR` |

使用浏览器识别的语言标签，例如 `en`、`zh-CN` 或 `fr-FR`。空白单元格和缺失的译文显示为未翻译，可以直接编辑。未命名译文与带标签的译文应放在不同文件中。给旧文件的目标语言命名前，工具继续按单目标语言格式导出。

导出 CSV 时，工具会给可能被电子表格识别为公式的值加一个前置单引号。需要逐字保留原始文本时，请导出 JSONL。

## 开发

使用 Node.js 24 和 pnpm 11 安装开发依赖并生成独立文件。

```sh
pnpm install --frozen-lockfile
pnpm build
pnpm check:build
pnpm test
pnpm test:browser
```

浏览器测试默认使用已安装的 Edge。可设置 `BROWSER_PATH` 指向其他已安装的 Chromium 浏览器。安装 TypeScript 后，可运行 `tsc --strict --noEmit tests/full-tool-contract.types.ts` 检查接口声明。
