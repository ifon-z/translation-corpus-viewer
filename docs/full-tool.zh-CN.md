# 完整版对照与接口参考

[English](full-tool.md) · 简体中文

**公开版**以静态页面处理用户选择的 JSONL 或 CSV 文件。**完整版**还提供 Python CLI，以及访问本地语料库的网页服务。[TypeScript 接口声明](../contracts/full-tool.d.ts)保留完整版的本地 HTTP 接口和 CLI 提交模式，仅用于类型检查。打开公开版页面无需启动服务器，也不会向平台发出请求。

## 功能对照

| 功能 | 公开版 | 完整版 |
| --- | --- | --- |
| 查看译文 | 搜索和筛选一个已导入的文件，可切换文件包含的目标语言 | 列出已保存的模块，按模块和语言对浏览词条 |
| 编辑与校验 | 在浏览器中编辑，标出空译文、占位符或标记差异 | 单独保存本地编辑，并与保存的译文比较 |
| 存储与导出 | 下载整份工作文件，支持 JSONL 和 CSV | 按模块和语言对保存 JSONL、CSV、快照及变更记录 |
| 核验抓取数据 | 校验导入结构和译文文本 | 比对抓取分页、导出文件和已保存的元数据 |
| 目录与抓取 | 提供请求和响应声明 | 搜索或刷新目录，抓取指定模块并报告任务进度 |
| 提交 | 提供提交预览和 CLI 模式声明 | 预览本地编辑，并提供单独的 CLI 实际提交模式 |

公开版保留 `id`、`context`、`source`、可选的源语言标签和一个或多个目标语言。单目标文件与带语言标签的文件见[格式说明](../README.zh-CN.md#文件格式)。如果需要从有权处理的完整版文件保留词条 ID，请在导入前将 `trk_id` 映射为 `id`。完整版的历史和提交元数据保存在其语料库中。

## 完整版 CLI

下表列出完整版的命令。公开版通过 `index.html` 运行。

| 命令 | 用途及主要选项 |
| --- | --- |
| `catalog` | 读取或刷新模块目录，支持 `--search` 和 `--refresh` |
| `crawl` | 按 `--source` 和 `--dest` 指定的语言抓取选定的 `--modules`。使用 `--dry-run` 可比较结果而不更新语料。 |
| `modules` | 列出已保存的模块和语言对 |
| `show` | 查看指定的 `--module`，可用 `--find` 筛选 |
| `verify` | 报告已保存语料与抓取数据之间的差异 |
| `edit` | 为指定的 `--module` 和 `--trk-id` 记录或清除本地编辑 |
| `submit` | 默认预览。实际提交仅支持 CLI，需同时指定 `--live` 和 `--yes`。 |

## 完整版本地 HTTP 接口

下表描述完整版的本地服务器。公开仓库中的 `FullToolHttp` 声明记录对应的数据结构。提交预览中的平台专用载荷以对象表示，具体字段由平台决定。

| 路由 | 输入 | 成功响应 |
| --- | --- | --- |
| `GET /api/modules` | 无 | 已保存的模块、语言对和计数 |
| `GET /api/entries` | 查询参数 `module`、`source` 和 `dest` | 含本地编辑和校验结果的词条 |
| `GET /api/catalog` | 无 | 缓存的目录 |
| `GET /api/history` | 查询参数 `module`、`source` 和 `dest` | 快照和变更记录 |
| `POST /api/task` | `kind: "catalog"` 表示目录任务，`kind: "crawl"` 和 `modules` 表示抓取任务 | 带 ID 的任务状态快照 |
| `GET /api/task` | 查询参数为任务 `id` | 任务状态、输出日志及退出码 |
| `POST /api/edit` | 语言对、`trk_id`、`text` 及可选的 `note` | 保存后的本地编辑 |
| `POST /api/clear` | 语言对和 `trk_id` | 本地编辑是否已清除 |
| `POST /api/submit-preview` | 语言对 | 可提交和被拦截的词条，以及警告 |

实际提交由完整版 CLI 提供。实现或使用独立集成前，请阅读[使用与责任](../README.zh-CN.md#使用与责任)。
