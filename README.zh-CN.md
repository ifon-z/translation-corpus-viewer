# 翻译语料查看器

[English](README.md) · 简体中文

浏览、搜索、编辑和校验本地 JSONL 或 CSV 文件中的双语词条。公开版在浏览器中运行，并附有完整版目录、抓取任务、语料 API 和提交流程的[接口声明](contracts/full-tool.d.ts)。

## 快速开始

1. 下载并解压仓库，在浏览器中打开 `index.html`。
2. 选择本地 JSONL 或 CSV 文件，或从侧栏载入虚构样例。下方也提供独立的样例文件。
3. 搜索或筛选词条，编辑译文，查看空译文、占位符和标记差异的提示。
4. 将整份语料导出为 JSONL 或 CSV。重新打开导出的文件即可继续编辑。

双击页面即可使用，无需安装软件、登录账号或启动本地服务。编辑暂存在当前页面，导出后由你保存。搜索和筛选只影响页面显示。

### 示例一 · BGA 风格桌游

载入 **BGA 风格桌游**，或导入[桌游 JSONL](examples/bga-style-demo.jsonl)。样例包含 6 条虚构的英中词条。选择 **校验有提示**，可以找到空译文、漏掉的占位符和缺失的标记。编辑 `orchard-demo-03`，在译文中保留 `{bellTime}`，再导出 JSONL 保存草稿。

**免责声明。** 游戏文案、译文和 ID 均为虚构。此示例未使用 BGA 数据，也不会连接 BGA。本项目独立维护，与 BGA 无隶属或背书关系。访问 BGA 平台须遵守其使用条款。[BGA 使用条款](https://fr.boardgamearena.com/legal?section=tos) · [使用声明](NOTICE.zh-CN.md)

### 示例二 · 写作应用界面本地化

载入 **应用界面文案**，或导入[应用界面 CSV](examples/app-ui-demo.csv)。查看一款虚构写作应用的导航标题、状态消息和多行导出说明。选择 **未翻译**，补写 `ui-demo-04` 的译文，再导出 CSV 交给同事。

## 公开版与完整版

公开版提供本地文件工作流。完整版还包括模块目录、抓取任务、写入磁盘的语料和快照，以及提交流程。公开仓库通过类型声明和参考文档保留这些接口。详见[版本对照和接口参考](docs/full-tool.zh-CN.md)，其中列出了功能、命令名称和本地路由。

## 文件格式

文件使用 UTF-8 编码。JSONL 每行包含一个对象，CSV 第一行为表头。词条必填字段为 `source`，可选字段为 `id`、`context` 和 `target`。公开版使用这四个字段导入和导出。

导出 CSV 时，工具会给可能被电子表格识别为公式的值加一个前置单引号。需要逐字保留原始文本时，请导出 JSONL。
